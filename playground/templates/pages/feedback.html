gth-toast (failed requests)

toast.js toasts any failed htmx request on its own: 4xx/5xx (a FastAPI JSON detail becomes the message), network failures and timeouts. It stays quiet for 422 (inline form errors), when the response sends its own toast, and inside data-gth-error-toast="off".

For a network failure, switch DevTools to offline and press any button.

gth-toast (static flashes)

The other delivery mode — a server-side flashes list in the same markup, rendered inline here (they'd normally live in the toast container, see docs/contract.md). Same options: title, icon, action, variant.
